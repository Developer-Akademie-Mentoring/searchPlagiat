# SearchPlagiat

## Was das ist

Sucht nach Plagiaten in Github-Repos

## Tech Stack

- Vanilla JavaScript

## Konventionen

- Kommentare auf Englisch
- CSS Klassen nach BEM bennen
- Variablen und Funktionen auf Englisch camelCase
- Funktionslängen sollten ca bei 14 Zeilen Code bleiben (mehr ist imer dann ok wenn sinvoll)
- Erstelle bei jeder funktion direkt JSDoc in englisch (dabei nicht mehr als ein Stichpunkt Beschreibung pro Funktion)

## Regeln

- Installiere keine npm packages selber
- Jede Änderung in logs/debug.log dokumentieren
- Keine neuen Dateien ohne Rückfrage anlegen

## Verhalten

- Wenn Anforderungen unklar sind: nachfragen, nicht raten
- Lieber eine kurze Rückfrage als falsch umsetzen
- Bei größeren Aufgaben erst den Plan zeigen, dann umsetzen
